# 近两年：文稿

每段从第一句直接念到最后一句。小标题不用念。

## 本地把模型跑起来

### Ollama

今晚这台电脑就能自己答你，稿子不用先发到别人的网站上。你打一行字，它就在这台机器里回你，像身边多了个同事，只是你不用再开一个网页。平时想试个模型，得先弄懂环境、显卡和一堆文件格式，试一次跟搬家一样，试到一半人就烦了。今晚先别搞那么大。你就让一个模型在自己电脑上开口，听见它说话了，再接到你现在用的编辑器上。Ollama 做的就是这件事，把下载、运行、留一个本地接口，收成一下。

### llama.cpp

一个问题，其实不用先把模型送到机房里。同一颗模型，换成更小的量化版本，原来塞不进内存的，现在塞得进。笔记本只剩 CPU，也有机会让它把一句话答完。原始那包权重又大又挑环境，一打开就说内存不够，人很容易直接放弃。你先别追最新最大的那个。找一个允许你用的、已经量化好的小模型，让它在你自己的机器上连续答三句。llama.cpp 负责的是把这次计算跑完。这个模型能不能拿去商用，得另看它自己的许可。

## 少装一套工具

### uv

明天你要新开一个 Python 小工具，环境可以自己搞定，不用再抓个人来看。别人还在等原来的安装转圈，你这边依赖已经就位，可以开始写第一行。这种烦你肯定遇到过。电脑上已经有三个 Python，项目要的是第四个。虚拟环境忘了开，包装进了系统里，第二天换台电脑，同样的脚本就跑不起来。你拿一个旧脚本试试就行。用 uv 给它单独的环境和依赖，这个脚本跑通了，以后新项目都按这一下。装包、虚拟环境、Python 版本，它收在同一个地方。

### Ruff

你提交上去的 Python，不用再因为引号和导入顺序被人打回来。原来这点事要记三套命令，现在记一套就够。格式化过了，导入顺序又报错，报错修完，换台电脑版本还不一样，来回就耗在这些上面。你先只拿一个文件夹试。它标出来的要是你自己也认得的问题，再放到整个仓库上。Ruff 管的是检查和格式，功能怎么设计，还是你来想。

### Bun

今晚你就可以让一个小接口在自己电脑上答应你一次。跑 JavaScript、装依赖、打包、跑测试，平时常常是四个工具四个名字，这里先记 Bun 一个。新项目业务还没写，半小时已经耗在版本和配置上，这种开头最磨人。你做一个只有一个文件的小接口，它能回你，这条路就通了。真要拿去发给别人用，先看一下许可：Bun 自己是 MIT，装好的程序里还带了别的组件，分发之前翻一下条目正文。

### Biome

团队不用再为了一个括号是谁改的，吵掉一整版。格式化一份配置，检查又一份配置，新人第一天就在两份文件里迷路，改一行代码，旁边跟着三行无关的格式变化。你先拿一个新的小页面，让 Biome 在保存时把格式和基本检查做完。看着顺眼，再慢慢换掉旧项目里重复的那一部分。

## 写代码的那扇窗

### Zed

两个人改同一份代码，不用再开着屏幕共享，一个说往下一点，另一个拿鼠标去找。窗口是原生的，打字不用先等一个网页壳醒过来。你们先一起打开一个练习仓库，改同一个文件，能看见对方的光标，这就成了。Zed 把一起改放进编辑器里面。它的许可证是 GPL，你要拿去改完再发给别人，先看条目里怎么写。

### Ghostty

你的命令、快捷键、仓库都留在原地，换掉的只是那扇终端窗口。日志刷得很长的时候，字还跟得上你的眼睛，不会一密起来就把整扇窗拖慢，慢到你以为是电脑不行了。你先只把一个常开的项目换成 Ghostty，命令照旧敲。这个顺了，再换下一个。它是一个新窗口，不是一门新的命令语言。

### Astro

你的说明页可以先被打开，不用先加载一整套用不上的应用。看起来还是一个网站，脚本只留在真正会动的那一小块上。用做后台的框架去写一篇博客，打开文章要等一堆代码，读者还没看见字，页面已经先忙了半天。你把一篇已经写好的说明放进去，发出去能打开，就算这一步完成。以后真要互动，再加那一块。

### htmx

一个老网页也可以点一下就更新一块，不用先把整站重写成单页应用。你按那个按钮，请求出去，回来的是一块页面，放回原来的位置，别的地方不动。就为了一个筛选列表，先选框架、再打包、再管状态，工程比功能先大一圈。你找页面上已经有的一块列表，让它按条件自己刷新。这块能换，你就知道这条路走得通，整站不用当天推翻。

## 表格和日志

### DuckDB

今天下班前，你可以拿一句 SQL 回答这个表里谁最大。表还躺在文件夹里，查询已经跑完，不用先把文件倒进一个数据库。为了问一次，去装服务、建表、导入，问完了服务还丢在那儿，下次还得想起来关。你拿一份自己看得懂的导出表，按日期汇总一句。DuckDB 就待在你现在的程序里，没有另一台服务器要养。

### Polars

那份每次打开都要等的表格脚本，可以先变短，也可以先变快。你告诉它要哪几列、怎么分组，它按列去算，你不用自己写循环，一行一行搬。数据一多，旧写法先卡在内存和等待上，人很容易觉得是不是该上一个大集群了。你先把「读进来、筛一下、求个和」这一段换成 Polars。数字对得上，再换下一段。它适合你手头这种中等大小的表，公司的数据仓库是另一回事。

### ClickHouse

线上出了状况，你有一个专门回答统计问题的地方，记订单的那个库继续干活。过去一小时哪种错误最多，按接口、按错误码问，这种问题它接得住。日志如果一直塞在订单库里，一查报表，下单也跟着慢。你先只接一种日志，留几天，做出「错误最多的接口」这一张。这张能答上来，再加第二种。它是拿来分析的，别把它当成唯一的账本。

## 放在自己机器上的产品

### Immich

家里可以有一本自己的相册。人换了手机，照片还在你的硬盘上。翻的时候还是一条时间线，只是服务器换成了你家那台。空间要钱，条款还得自己猜，哪天账号出问题，整本相册一起着急。你先备份一个相册就好，别第一天就把十年的照片全搬过去。浏览器里能看见这批，再开自动备份。硬盘会坏，异地再留一份，这个软件不替你保证盘子永远没事。

### Jellyfin

客厅可以有一个不绑厂商账号的片库。文件还是那些文件，打开之后是一面海报墙，像一个你自己的播放站。片子散在硬盘各处的时候，找一集要翻文件夹，换个设备，看到哪了也丢了。你先放进两部你有权播放的片子，在浏览器里看完一集，进度还在，再去整理剩下的。片源它不提供，你放进去什么，它就播什么。

### Home Assistant

你进门，灯可以按你定的条件亮，这条规则写在你家的机器上。一个门磁，一盏灯，打开就亮，先从这么小的一条开始。每个电器一个 App，人还没出门，规则已经散在好几家的云上，离家之后才发现自己做不了主。你只接一个已经买回来、它也认识的设备，做成一条自动化。这条成了，再加第二个。全屋不用第一天就改完。

### PocketBase

你的小想法可以有人注册，也可以记下东西，不用先租一整套后端。数据库、登录、文件，这次先记成一个程序。做一个给十个人用的登记页，也要先摆开服务器、数据库、登录三套东西，还没写页面，人已经累了。你做一个只记名字和一条备注的页面，自己注册一个用户，存进一条数据。这条通了，再加文件，或者再加谁能看。它适合这种小应用，人多到要分团队管的平台，不是它这一下能包的。

### n8n

每天你手工复制的那一下，可以变成到点自己发生。左边一个触发，右边一个动作，中间不用先写完一整套服务。数据从表格搬到通知，人夹在中间当搬运工，周末也得盯着，这种活最亏。你只挑一件每周都在做的搬运，到点从一处取出来，送到另一处。跑通一次，再去加分支。n8n 很多人在用，不过它现在的许可证是 Sustainable Use License，不是开源许可。跟别人说的时候，别把它说成一个开源自动化神器。

## 把模型做成服务

### vLLM

你的模型可以变成一个接口，同事排队来问，机器不用被一轮一轮的对话白白占着。十个人一起问的时候，它会想办法把这些请求拼在同一张卡上算。笔记本上自己聊得好好的，一放到给大家用，显存和等待一起爆，每个人独占一次，卡还在空转。你先拿一个允许你部署的模型，开一个只有自己会调的接口，连续问它五句，看它还在不在。vLLM 管的是这次服务能不能接住更多人。模型本身能不能用，还是看那份权重自己的许可。

### ComfyUI

你满意的那套出图步骤，可以留下来，不用只存在脑子里。每个方块做一步，线接到下一步，改其中一格，整条还在，下次换个词就能再跑。脚本改着改着，上次哪几个参数好看就忘了，想再来一张，只能翻聊天记录。你先跑通最简单的一条，提示词进去，图出来。图能出来，再加放大，或者再改一版。模型它不白送，能不能用，看你下载的那一份。这个软件本身是 GPL-3.0。

### Open WebUI

模型已经在你电脑上跑起来之后，家里人打开浏览器就能问，不用先学命令行。后面还是你自己的模型，前面变成一个聊天页，能登录，也能换着聊。命令行只有你会开的时候，人一多，大家都来问那个窗口在哪。你先把自己的账号配上一个已经在跑的模型，问成功一句。这一句通了，再决定要不要开给第二个人。这个界面现在的许可证不是开源许可，源码看得到，品牌和用的人多了以后还有额外限制。别跟别人说它是个开源聊天神器。

### Dify

你可以把「先查资料，再按这个格式回答」做成一个别人打得开的入口。查资料是一格，模型是一格，输出格式是一格，整件事不用写成一个看不懂的大脚本。演示的时候模型很会说，一碰到你自己的文档就开始胡编，同事还看不见它中间是怎么走的。你先上传一份短资料，做三步：接收问题，找出相关的那段，按固定格式回答。这一份答对了，再把文档加长。Dify 用的人很多，不过现在的许可是改过的 Apache 条款，多租户和品牌上还有限制，不能把它说成 Apache-2.0 的开源软件。

# 实用开源项目志

按用途收集热度高、真正被广泛使用的开源软件。每一篇都单独说明：它解决什么问题、核心功能、通常放在工作流的哪一步、边界在哪里、许可证现在怎么算。

这不是星标排行榜。星标只作为热度旁证，统计日写在每篇开头。行业默认、但 GitHub 镜像星标不高的项目，例如 PostgreSQL，照样收录。许可证已经离开开源定义的著名项目也会收录，并写明替代分支，避免把「仓库还能看到源码」误写成「仍然是开源软件」。

## 怎么读

主文件只做目录。热度拆成两页：[历史最高](catalog/历史最高.md) 是长期默认，[当前热度最高](catalog/当前热度最高.md) 按日、周、月看趋势。用途分类每种一页。项目说明仍在 `entries/`，五节顺序固定。

机器可读目录在 [`catalog/index.json`](catalog/index.json)。分类定义在 [`catalog/categories.json`](catalog/categories.json)。新增一篇的规则在 [CONTRIBUTING.md](CONTRIBUTING.md)。想用口语把项目讲清楚，看 [`文稿/近两年.md`](文稿/近两年.md)。

本仓库的文字使用 [CC BY 4.0](LICENSE)。项目名称和上游代码仍属于各自的所有者，许可以各篇正文为准。

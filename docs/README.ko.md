## 별 개수보다 실제 용도로 소프트웨어 선택하기

작업 흐름별 분류에서 후보를 찾고 제약과 라이선스를 읽은 뒤 원본 프로젝트를 방문하세요. 별 개수는 날짜가 있는 관측값이지 실시간 순위가 아닙니다.

### 실용적인 오픈소스 선택 안내

| → | |
| --- | --- |
| [분류 보기](../catalog/categories/) | JSON / source |
| [카탈로그 JSON 읽기](../catalog/index.json) | Browse |

이용 안내는 5개 언어이며 프로젝트별 글은 중국어입니다. 추세는 2026-10-10에 수집한 기록입니다. 소스 공개가 곧 오픈소스를 뜻하지는 않습니다.

### 카탈로그 다시 생성

```bash
python3 scripts/build_index.py
```

출처를 표시하여 글을 공유·수정할 수 있습니다. 원본 코드는 각각의 라이선스를 따릅니다.<br>(CC BY 4.0)

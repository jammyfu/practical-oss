## スター数だけでなく用途からソフトウェアを選ぶ

分類から候補を探し、制約とライセンスを確認してから上流プロジェクトへ進みます。スター数は日付付きの記録であり、リアルタイムの順位ではありません。

### 実用的なオープンソース選定ガイド

| --- | --- |
| [分類を見る](../catalog/categories/) | JSON / source |
| [カタログ JSON を読む](../catalog/index.json) | Browse |

利用ガイドは5言語、各プロジェクトの記事は中国語です。トレンドは2026-10-10のスナップショットです。ソース公開とオープンソースは同義ではありません。

### カタログを再生成

```bash
python3 scripts/build_index.py
```

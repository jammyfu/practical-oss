## 它解决什么问题

界面稿如果只活在专有设计工具里，文件格式、席位和插件都绑在那一家。设计师交出的图层，开发还要再猜成 CSS。Penpot 把设计和原型放在浏览器里，布局用 CSS Flex 和 Grid 这一类 Web 自己的办法，检查面板能看到对应的标记，文件也可以放在自己的服务器上。

## 核心功能

- 矢量设计和组件。画板、组件、变体和共享库用来维持同一套界面，而不是每页复制一份。
- 按 Web 来排版。Flex 和 Grid 让稿面上的结构和样式表靠近，而不是另一套只存在于设计工具里的约束。
- 协作和原型。同一份稿可以一起改，也能串成可点击的流程。
- 自建或使用官方站点。设计数据不必只留在厂商的云上。

## 通常怎么用

要离开按席位计费的设计工具、又希望设计和前端用同一套布局概念的团队，会从 Penpot 2.0 这一代开始评估。2024 年 4 月的 2.0 换了组件系统并加上 CSS Grid。公共部门、设计系统小组和想自己保管文件的公司，会把它接到现有账号系统上。个人画一张草图，不一定需要把整套服务架起来。

## 它不负责什么

Penpot 不把设计稿变成可上线的前端应用，生成的标记只是对照。它也不管理组件在代码仓库里的版本，那一步仍是前端的事。字体、图片和品牌资产的版权不因工具开源而改变。官方另有付费的 Enterprise 方案，面向组织和流程治理；这不改变仓库里设计平台本身的许可。

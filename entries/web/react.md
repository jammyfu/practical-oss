## 它解决什么问题

界面状态一多，直接改 DOM 会散落在事件回调里，很难看出「当前数据应该对应哪一屏」。React 让你把界面写成状态的函数：状态变了，就重新描述界面，由库把差异应用到页面上。

## 核心功能

- 组件。一个按钮、一张列表或一整页都可以是带输入和状态的组件。
- 声明式渲染。描述结果，而不是一步步命令 DOM。
- Hooks。在函数组件里保存状态、处理副作用和复用有状态逻辑。
- 渲染器可替换。同一套组件模型可以面向浏览器 DOM，也可以面向原生视图。

## 通常怎么用

新的 Web 应用、设计系统和很多管理后台会选 React。它常和路由、数据请求库、打包器一起出现。Next.js 等框架在它外面补上路由、服务端渲染和部署约定。只需要一个静态页或轻交互时，原生 HTML 或更小的库就够了。

## 它不负责什么

React 不提供路由、请求库、表格或完整的项目结构。官方仓库是界面库，不是应用框架。性能也不会因为使用了 React 就自动变好，列表、状态放的位置和重复渲染仍要自己看。

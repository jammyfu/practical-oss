## 它解决什么问题

传统打包器在开发时也要先把整个应用打成包，项目一大，改一行要等很久才在浏览器里看到。Vite 在开发服务器里直接利用浏览器的 ES 模块，只在浏览器请求到某个文件时才转换它，所以冷启动和热更新短很多。

## 核心功能

- 开发服务器。按需编译 Vue、React、TypeScript 和 CSS。
- 热模块替换。改一个模块时尽量不刷新整页。
- 生产构建。使用 Rollup 把开发时的模块图收成可部署的静态资源。
- 插件接口。框架和预处理器通过插件接入，而不是各自重写一套服务器。

## 通常怎么用

新的 Vue 和 React 项目很多把 Vite 当作默认脚手架。它也用来给组件库做本地预览。服务端渲染、复杂的模块联邦或非常老的浏览器兼容，可能还要加插件，或者继续使用专门的应用框架。

## 它不负责什么

Vite 不是界面框架，也不处理接口和数据库。它不决定目录结构之外的业务架构。生产环境的性能主要取决于打出来的资源和运行时框架，开发服务器快不等于上线以后就快。

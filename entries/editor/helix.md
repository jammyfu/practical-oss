## 它解决什么问题

想用键盘模态来改代码的人，常常要先给 Neovim 配一套插件，语法、语言服务和多光标才算齐。配不好，编辑器还没开始写字，就已经变成另一个项目。Helix 把这些收进编辑器自己：打开文件就能高亮，能跟着语言服务跳转，也能同时改多处。

## 核心功能

- 模态编辑。先选中范围，再决定怎么改，快捷键集中在一份说明里。
- 多光标。同一类改动可以一次落在多个位置，不用再录一段宏。
- 语法和语言服务。tree-sitter 负责高亮和结构化编辑，语言服务负责补全、诊断和跳转。
- 终端里运行。配置是一份文件，不靠插件市场把功能一件件装齐。

## 通常怎么用

已经习惯 Vim 键位、又不想维护一份大型 Neovim 配置的人，会把它放进每天写代码的终端。远程机器上改配置、看日志、改脚本，也用同一套。要和别人同时改一个缓冲区、或者用大量图形界面插件时，仍然会留在 Zed 或 VS Code。

## 它不负责什么

Helix 不是 Neovim，原来的插件和 Vim 脚本不能直接搬过来。它也不提供 VS Code 那种扩展市场，调试器、特定语言的图形界面要看语言服务自己能做什么。版本管理、构建和测试仍在编辑器外面。它是 2020 年就开始的项目，近两年变常见，不代表它已经换掉系统里原来的编辑器。

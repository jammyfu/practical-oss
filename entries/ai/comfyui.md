## 它解决什么问题

一次图像生成要串起检查点、文本编码器、采样器、放大和局部重绘。这些步骤若写在脚本里，换一条流程就要改代码。ComfyUI 把流水线摆成节点图，让同一套步骤可以保存、改线，再拿来复用。

## 核心功能

- 可视化节点图，用来编排图像，以及项目已经支持的视频、音频等生成流程。
- 加载使用者自己准备的检查点、VAE、文本编码器和 LoRA 等组件。
- 工作流可以保存，并只重跑改过的部分，而不必每次从头执行整张图。
- 自定义节点用来补上官方图里还没有的模型或处理步骤。本地 API 可以让别的程序触发已有工作流。

## 通常怎么用

在自己的电脑上打开节点图，接入已经取得的模型，调整采样和提示，把满意的流程留下来批量出图。也有人让别的系统调用它的接口，把出图嵌进内容流程。官方云，以及图里那些通向闭源模型的合作节点，是另外的服务，不包含在这套本地程序的许可里。

## 它不负责什么

它不提供模型权重，也不授予任何权重的使用权。一个文件能被节点加载，只说明格式对得上，不说明你可以商用、再分发或拿去训练。权重的许可以发布者的条款为准。它也不是通用聊天产品，不替生成结果主张版权。官方云和付费 API 的账号、额度和服务条款要单独看。
